# 石巻圏 地域課題プラットフォーム（仮称）試作版

石巻市・東松島市・女川町で地域課題に取り組む人と組織をつなぐプラットフォームの、確認用の試作ページです。
掲載している団体・イベントはすべて架空のもの（ダミー）です。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | トップページ（知る・話す・一緒に動く・参加する・つなぎ役） |
| `groups.html` | 団体・企業を探すページ（課題・地域・種別・キーワードで絞り込み） |
| `css/style.css` | デザイン |
| `js/app.js` | データの読み込みと表示 |
| `data/groups.csv` | 団体の一覧（ダミー） |
| `data/news.csv` | 募集・お知らせ（ダミー） |

## GitHub Pages で公開する手順

1. GitHub にサインインし、右上の「＋」→「New repository」で新しいリポジトリを作る（公開設定は Public）。
2. 作ったリポジトリの画面で「Add file」→「Upload files」を選び、このフォルダの中身をすべてドラッグして「Commit changes」。
3. リポジトリの「Settings」→「Pages」を開き、「Branch」を `main`、フォルダを `/ (root)` にして「Save」。
4. 数分後、同じ画面に表示される URL（`https://ユーザー名.github.io/リポジトリ名/`）で公開されます。

各ページには検索エンジンに載らない設定（`noindex`）を入れています。ただし URL を知っている人は誰でも見られます。

## データの直し方

`data/groups.csv` と `data/news.csv` を Excel や Google スプレッドシートで開いて編集し、同じ名前の CSV（UTF-8）で保存して、GitHub に再アップロードします。

- `issues`（課題）は、複数あるときは `;` で区切ります。課題名は `js/app.js` の `ISSUES` と同じ表記にします。
- `url` は `https://` で始まるものだけがリンクになります。

### Google スプレッドシートに切り替える場合

1. 公開用のスプレッドシートを作り、`groups.csv` と同じ列名で入力する（作業用の名簿とは別のファイルにする）。
2. 「ファイル」→「共有」→「ウェブに公開」で、そのシートだけを「カンマ区切り形式（.csv）」で公開する。
3. 表示された URL を、`js/app.js` の `DATA_URLS.groups` に書き換える。

公開したシートは誰でも読めるため、掲載に同意した団体の、公開してよい項目だけを入れてください。

## セキュリティ上の配慮

- CSV の内容は、HTML ではなく文字として表示します（スクリプトの埋め込みを防ぐため）。
- 外部のライブラリやフォントは読み込んでいません。
- パスワードや API キーはコードに書かないでください。
